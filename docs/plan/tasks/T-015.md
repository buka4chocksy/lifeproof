# T-015 — NULLIF-harden RLS policies (GUC empty-string)

- **Task:** T-015 — NULLIF-harden RLS policies (GUC empty-string)
- **Owner:** dba
- **Depends on:** T-014 (list policy exists) — hardens T-010's RLS surface

## Objective

Harden every RLS policy that casts a session GUC to `uuid` so that an empty-string GUC (`''`, left by
`SET LOCAL` + rollback on a pooled connection) degrades to `NULL` and **fails closed** instead of raising
`invalid input syntax for type uuid: ""`. This removes the cast-error hazard flagged in D-020 before the
backend (T-010) builds on top of RLS.

## Acceptance (testable)

1. New migration `0003_*` changes the `USING` (and `WITH CHECK`, where present) expressions of the
   following 11 policies so every `current_setting('…', true)::uuid` becomes
   `NULLIF(current_setting('…', true), '')::uuid`. Prefer `ALTER POLICY … USING (…)` / `WITH CHECK (…)`
   (no DROP needed). The 11 policies:
   - `workspaces`: `workspaces_select_tenant`, `workspaces_insert_own`, `workspaces_update_tenant`,
     `workspaces_delete_tenant`, `workspaces_select_member`
   - `workspace_members`: `workspace_members_select`, `workspace_members_insert_tenant`,
     `workspace_members_update_tenant`, `workspace_members_delete_tenant`
   - `audit_events`: `audit_events_select_tenant`, `audit_events_insert_tenant`
2. Migration applies cleanly and idempotently via `pnpm db:migrate`.
3. Paste SQL evidence (run as `app_user`):
   - **(a)** with `app.current_user_id = ''` (empty string) set, `SELECT * FROM workspaces` returns
     **zero rows with no error** (previously it raised a cast error);
   - **(b)** with `app.workspace_id = ''`, `SELECT * FROM workspaces` returns zero rows with no error;
   - **(c)** regression: normal behavior is unchanged — a real `app.current_user_id` (owner/member) still
     lists its workspaces; a real `app.workspace_id` still returns get-one; cross-tenant still returns
     zero rows (re-verify T-014 evidence (a)–(e) still hold).
4. No grant-set changes; no `FORCE ROW LEVEL SECURITY`; no plaintext secrets/PII.
